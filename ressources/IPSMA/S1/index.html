Cinq cartes, cinq contraintes. Gardez celles qui vous inspirent, retirez les autres, puis rédigez le schéma quinaire dans le carnet en dessous.

Le carnet

Trois à cinq lignes par étape, au présent, dans le point de vue tiré. Ce que vous écrivez reste dans ce navigateur jusqu'à ce que vous l'effaciez.

L'équilibre de départ : le cadre, le personnage, son état.
L'événement qui rompt l'équilibre et déclenche l'histoire.
Comment le personnage réagit, ce qu'il entreprend. La tension monte.
Comment le conflit se dénoue, dans un sens ou dans l'autre.
Le nouvel équilibre. En quoi diffère-t-il du départ ?
Un seul. Puis deux phrases pour dire pourquoi celui-là, dans ce récit-là.
Ce que le lecteur pourra changer. Ce qu'il ne pourra pas changer. Ce qu'on attend de lui.
